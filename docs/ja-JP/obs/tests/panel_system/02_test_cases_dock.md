# Dock UI 単体テストケース定義  
**テストID体系：OBS-PANEL-Dock-TC-xxx**

Dock UI は Control Core が生成するメッセージ (`page.update`, `button.click`) を  
正しく表示し、ユーザー操作を正しく送信するビュー層であり、  
ここで定義するテストは外部仕様として扱う。

---

## 1. 目的

OBS Dock UI が **Control Core のメッセージ仕様に完全準拠すること**を保証する。

- ページの DOM 反映  
- ボタンクリックの送信  
- 接続状態表示  

以上の UI 仕様を自動テストで担保する。

---

## 2. テスト範囲

| 対象        | 内容                                   |
|-------------|----------------------------------------|
| page.update | DOM ボタン表示・ラベル反映             |
| button.click| 送信内容の形式と値                     |
| 接続状態    | CONNECTED / DISCONNECTED / ERROR の表示 |

---

## 3. テストケース一覧（外部仕様テスト）

以下のケースは Dock UI の外部仕様として **変更禁止** とする。  
テストID：**OBS-PANEL-Dock-TC-001〜004**

---

### OBS-PANEL-Dock-TC-001  
### page.update → DOM ボタン反映

**条件**

- `currentPage = "main"`  
- `buttons` に `{ x:0, y:0, label:"LIVE" }` を含む  

**手順**

- 疑似 WebSocket から上記 `page.update` を Dock UI に送信する。

**確認**

- (0,0) の DOM 要素に `"LIVE"` が表示される。  
- 対象セルに `.btn` クラスが設定されている。

---

### OBS-PANEL-Dock-TC-002  
### 未定義セルの扱い

**条件**

- 3x5 グリッドのうち、一部のセルのみ `buttons` 定義が存在する。

**確認**

- 未定義セルには `.btn.disabled` が付与される。  
- ラベルは空欄のままである。  
- 未定義セルをクリックしても `button.click` メッセージは送信されない。

---

### OBS-PANEL-Dock-TC-003  
### クリック送信内容の検証

**条件**

- (0,0) に有効なボタン定義が存在する。  

**手順**

- 対象セル (0,0) の DOM 要素をクリックする。

**確認**

送信される WebSocket メッセージが次を満たすこと：

- `type = "button.click"`  
- `payload.page = "main"`  
- `payload.x = 0`  
- `payload.y = 0`  
- `payload.source = "dock"`  

---

### OBS-PANEL-Dock-TC-004  
### 接続状態表示の反映

**条件**

接続状態の変化を疑似的に連続発生させる：

1. 接続成功  
2. 切断  
3. エラー  

**確認**

`#status` 要素の表示内容が次のように変化すること：

- 接続成功時: `"CONNECTED"`  
- 切断時: `"DISCONNECTED - RETRYING"` または同等の文言  
- エラー時: `"ERROR"`  

---

## 4. 備考（重要ポリシー）

- 本ドキュメントに記載する Dock UI のテストは **外部仕様扱い** とし、  
  UI 仕様変更（文言・表示ロジック仕様の変更）が無い限り、テスト内容の削除・改変を禁止する。

- Dock UI 実装の内部最適化（クラス名整理、DOM 階層変更など）を行う場合は、  
  テストコード側の修正は許容されるが、  
  **ここで定義した挙動（表示結果・送信メッセージ内容）が変わらないこと** を必須条件とする。

- Dock UI での分岐網羅（カバレッジ 100%）は必須としない。  
  ただし以下の仕様は常にテスト対象とする：  
  - `page.update` によるボタン表示・ラベル反映  
  - ボタンクリックに対する `button.click` 送信内容  
  - 接続状態の UI 反映
