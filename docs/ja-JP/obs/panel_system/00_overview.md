# パネルシステム概要（panel_system）

## 1. 目的

共通の設定ファイル（panel.json）に基づき、以下を同期的に制御する。

- OBS 内のカスタムドック（仮想パネル）
- Stream Deck（3x5, 15キー）の物理ボタン
- OBS WebSocket を用いたシーン／配信／録画／ソース操作
- 任意の外部 HTTP/API 呼び出し

## 2. 特徴

- レイアウトとアクションを JSON で一元管理。
- ページ切替で Dock と Stream Deck の表示内容が同時に切り替わる。
- JSON 設定により、OBS 操作と外部サービス連携を組み合わせ可能。
- 実装はローカル常駐の Control Core を中心とした疎結合構成とする。

## 3. 想定ユースケース

- 配信・録画開始/停止のワンボタン制御。
- シーン／レイアウト切替。
- マイクミュート、BGM 音量操作。
- ステータス取得（例：外部ツールの状態を HTTP 経由で取得しボタンに表示）。
